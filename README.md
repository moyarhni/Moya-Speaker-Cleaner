# Speaker Cleaner Moya

Offline Android app for speaker cleaning and testing.

## Features

- Offline generated PCM tones; no audio assets or internet.
- Water mode: 100–200 Hz, default 165 Hz.
- Dust mode: 200 Hz–20 kHz with adjustable frequency variation.
- Speaker Test: 20 Hz–20 kHz, left/right/stereo.
- English and Persian UI with RTL support.
- Duration and intensity controls, 70% maximum amplitude, timer stop, audio focus, and single-playback protection.

## Safety

This app cannot guarantee removal of water or dust and is not a substitute for professional hardware repair. Use low intensity and short sessions. Stop immediately if the sound is uncomfortable or the speaker behaves unusually.

## Build

Requires Android Studio, JDK 17, Android SDK 35, and Kotlin/Compose plugin support. Open the repository root and run the `app` configuration.
